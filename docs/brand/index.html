BRAND IDENTITY · SEPTEMBER 2026

The agent that asks first.

Valmont Agent is a private, approval-first software assistant. It plans, writes, and validates code against real repositories — and does none of it without explicit human approval. This page is the identity system: mark, palette, type, voice, and imagery.

Nothing ships without you.

01

Brand core

Calm engineering discipline, made visible. Valmont Agent sells verified leverage, not autonomy: every plan grounded in the real repository, every change contained, every pull request gated by a person. There is no demo mode anywhere in the product — what you see is what ran.

Deliberate

Moves at the speed of proof, not the speed of hype.

Exact

Names the branch, the file, the command, the variable.

Transparent

Plans, diffs, logs, timelines — always the real ones.

Calm

No urgency theater, no exclamation marks, no dark patterns.

Stewardly

Treats the repository as someone else's property, because it is.

Values

  1. Consent before change. Two explicit approvals — before code is written and before a pull request is created — are the product, not friction to remove.
  2. Truth over theater. Live only. Missing configuration fails loudly; nothing is fabricated to fill a gap.
  3. Precision as care. Bounded retrieval, redacted secrets, restricted workspaces, exact command allowlists.
  4. The human signs. Never merges, never deploys, never force-pushes, never touches protected branches.

The mark tells one story

The checkpoint V: an ivory letterform — the work — resting on a copper band — the approval threshold — inside a navy field — the house. Every asset repeats this single idea: work stops at the copper line until a human moves it.

02

Logo system

The wordmark is drawn geometry — monoline, 5-unit stroke, 40-unit cap height, rounded terminals — not a font. Never retype it; always place the SVG from docs/brand/.

Clear space & minimum sizes

H/2 — CLEAR SPACE
  • Clear space on all sides: half the tile height (H/2). Nothing enters it.
  • Minimum widths — house lockup 96 px · product lockup 140 px · tile/glyph 16 px.
  • Below 24 px, use the tile only — never the lockup.
  • The threshold stays copper in every variant, except single-ink print.

Rules

  • Sentence case everywhere — buttons and headings included.
  • Tabular numerals for IDs, counts, timings.
  • No italics in UI; never fake weights with transforms.
  • Fallback stack: Avenir Next, Segoe UI, Roboto, Helvetica, Arial.
05

Voice

A senior engineer briefing a trusted colleague: precise, unhurried, honest about uncertainty. Say the true thing. Name the exact thing. Calm, not clever. Approval is a feature. No theater.

SAYPlan ready for your review — 4 files, 2 commands.
DON'T🎉 Your amazing plan is ready!!!
SAYPaused for your approval before writing code.
DON'TWaiting on user input…
SAYMODEL_API_KEY is not set. Set it and retry.
DON'TSomething went wrong. Please try later.
SAYPull request #42 created from valmont/task-17.
DON'TAll done! You're welcome!
SAYI can't merge — merging is outside my boundaries.
DON'TSorry, I'm not allowed to do that :(
SAYnpm test exited 1 — 3 failures in src/pay/.
DON'TSome tests failed.

Mechanics

  • Errors follow the pattern: what failed → why → the exact next step.
  • Present tense, active voice. Never blame the user; never apologize twice.
  • Banned words: revolutionize, supercharge, unlock, seamlessly, game-changing.
06

Imagery

Engineered calm. Flat, editorial, matte. Geometry carries the meaning; negative space carries the confidence. The palette is locked — navy, ivory, copper, slate, and nothing else. No hoodies-and-holograms stock, no glowing brains, no circuit-board clichés.

07

Applications & governance

Product UI

Tokens come from @theme in globals.css. Copper marks every approval gate — scan for copper to find every decision point.

Pull requests

Always from valmont/* branches. Copy states what changed, what ran, and what needs approval.

Docs & README

Ivory ground, navy headings, copper reserved for warnings that gate action.

Social & email

Avatar: the tile, never the lockup. Email: navy band with reverse lockup, one copper action per email.

Governance

  • Exact values live in code: src/app/globals.css. Logo geometry lives in docs/brand/*.svg and nowhere else.
  • Changes to palette, mark, or voice require brand-owner review and a version bump in docs/BRAND.md.
  • If a situation isn't covered, apply the test at the top of this page: does it ship without you? If yes, it isn't Valmont.
